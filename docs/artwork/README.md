# Kurasi gambar Refraction dari Freepik

Status: kurasi untuk peninjauan, belum mengganti gambar website. Repository menyimpan daftar sumber dan alat pratinjau lokal.

- 39 puisi dicakup; Halaman Nol dipertahankan.
- Satu kandidat cover tambahan disertakan sebagai opsi terpisah.
- Hanya kandidat yang terindeks sebagai Free Photo/Free Vector. Status gratis, kontributor dan lisensi final perlu dikonfirmasi pada unduhan resmi.
- Preview publik untuk perbandingan; bukan file final atau bukti lisensi unduhan. Jangan memakai preview ber-watermark sebagai aset website.
- Hasil final harus memenuhi bingkai 4:5 melalui crop proporsional, tanpa distorsi, tulisan atau watermark. Kredit diberikan di luar gambar sesuai lisensi.
- Kandidat yang pratinjaunya belum bisa diakses tetap memiliki tautan sumber; belum lolos pemeriksaan visual.

Buka http://localhost:4327/ ketika server preview aktif. Untuk membuat ulang dan menjalankan server lokal:

```sh
python3 scripts/preview-refraction-freepik.py
```

Gambar lama dan preview publik hanya disalin ke `/tmp/scratch-refraction-freepik`. Tidak ada file foto Freepik atau sumber editable yang dimasukkan ke repository. Data sumber ada di `refraction-freepik-candidates.json`; generator tidak menyentuh aset website.
